FATE link maker

pumps out tiny ~8 KB cloak links that stream FATE OS from jsDelivr — same trick stormOS uses. Upload FATE.html to the repo once, then mint as many links as you want.

idle

Each link is a cloaked Google page: type the keyword, hit enter, and it resolves the latest commit SHA (GitHub API → jsDelivr resolve API → saved copy → branch), then streams the file across cdn / fastly / gcore jsDelivr mirrors with a progress bar. One link = one small file, so a farm of thousands costs kilobytes, not gigabytes.
